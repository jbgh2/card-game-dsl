# Issue #1041: the fix options, measured — 2026-11-07

**This is a dated report. Its counts describe the tree at branch
`ccr-7d20835d-yaodab` on 2026-11-07 and do not update. The living spec is in
`docs/`.** It measures and recommends; nothing here is built, and the operator
rules.

Class: bug — Merge Lane B for every option measured (`tools/lane-of.sh` on
`cardlang/runtime/observe.py`, `cardlang/openspiel/infostate.py`,
`cardlang/resolve.py`); no option touches `cardlang/grammar/`. Reachability R2
(issue #1041's own tag).

## The question

A State Variable written from something some seat cannot see, shown to a seat
at a decision and overwritten before its next decision, is forgotten: no
Observation Event records the write, and the information state renders only
the current value (issue #1041; witness `witnesses/state_recall.cardlang`;
Coq `state_recall_forgets`). The issue names two fixes — log every
assignment, or refuse the flow — and the brief adds a hybrid. This report
measures all three against the corpus, adds a fourth found while measuring,
and recommends one.

## What was measured, and how

`probe_assign_hidden.py` (this directory; strict-mypy clean). Run:
`python experiments/infoset_proofs/probe_assign_hidden.py --lines 6`.

- **Static half — the checker's own read analysis.** A subclass of
  `resolve._HiddenReads` replays the checker's walk over the resolved tree
  (game plus spliced libraries) and judges every State Variable write site —
  `AssignStmt.value` and `.index`, and a phase `state` default, the writes
  `resolve._STATE_WRITE_SITES` names that carry an expression — with the
  checker's own `_judge` against `_NO_SEAT`. That is the
  `READ_POSITION_NO_SEAT` verdict (`stdlib.zones.reveals`: every seat must see
  what the read needs), so a refused read here is exactly what option 2 would
  refuse. A `choose` result is excluded: it is announced (`announce` event).
  Separately it flags a write whose enclosing statement-level control
  position (`if` condition, `repeat until`, `as`, a `turns` clause) reads what
  some seat cannot see: the **implicit flow**.
- **Dynamic half — six seeded uniform lines per game** (`replay.LiveLine`),
  with a taint over State Variable slots: a slot is tainted by a flagged site
  that wrote it or wrote a slot its value was computed from (`+=`/`-=` keep
  the slot's taint). At each decision it records what the decider is shown.
  - *shown then changed*: a tainted value shown to a seat at one decision and
    different (or out of scope) at its next — the forgetting precondition;
  - *transient*: a tainted value overwritten before any seat decided — an
    announcement no decision-time view ever showed;
  - the event volume each logging option would add.
- **Recall oracle at depth.** `probe_recall_corpus.py` re-run with its sample
  points moved past the first deals (picks 40-160, four lines).

What a green here does not prove: the walk covers the write sites the
checker reaches (every `AssignStmt` in every corpus game was reached); the
control flag follows statement nesting only, not a move type's effect under
the round or offer that asks it, nor a `produce` tag into its `produces:`
arm; the taint does not follow a Primitive's own State Variable reads, so
*transient* is an upper bound for games whose writes call natives (the poker
stacks); the dynamic half is sampled; a forgetting precondition is a recall
failure only where the value is not derivable from the seat's log.

## The options

### Option 1 — log every assignment

A new Observation Event kind per write, to every seat.

- **Recall.** Held by construction for the state half: Coq `pub_from_log`.
  It closes the implicit flow too.
- **Semantics.** The literal reading of "state is public … always" and of
  resolve's "an assignment is an announcement": a value written and
  overwritten between two decisions is heard. That can refine the partition
  where a transient tainted value is not otherwise derivable. The candidates
  measured are cribbage's pegging state and coup's challenge outcome, so the
  partition moves in more than the games that forget.
- **Rung.** It needs one door onto persistent state, and there is none today.
  `execute._assign` mutates an indexed variable's dict in place
  (`target[key] = …`) past `RuntimeState.set`, and `declare` and the `again`
  clear are further doors. The door has to be built first.
- **Cost.** 26 of 37 first-decision strings move, so it collides with epic
  #999's finish line 8 ("`infostate_format.json` unchanged") and is exactly
  its operator step (a). Logs grow by 69% overall; big-two adds 470,164
  events to 93,932.
- **Surface totality.** The new kind joins `EVENT_PAYLOADS`. The
  per-visible-fact matrix certifies its fields, and
  `tests/test_observation_payloads.py` must reach it. No grammar.

### Option 2 — refuse the flow

Judge `AssignStmt.value` as `READ_POSITION_NO_SEAT`.

- **Corpus.** It refuses 16 of 37 games: belote, big-two, canasta, cribbage,
  five-card-draw, five-card-stud, french-tarot, getaway, gin-rummy, hearts,
  holdem, holdem-heads-up, pinochle, seven-card-stud, skat, tichu.
- **False positives.** In 12 of the 16 the published value is derivable (the
  table above). The judgement is by zone type and flow-insensitive:
  - a poker showdown moves the hole cards to a public zone first, but
    `pot_share` names `hole`;
  - a Hearts lead is `player_holding(2 of clubs)`.
- **No remedy.** The issue's honest form, "a `reveal` before the
  assignment", does not satisfy the judgement: `reveal` shows one card, and
  nothing in the checker sees that it came first.
- **The implicit flow.** It does not close it (the second witness) unless the
  `_CONTROL` rows are judged too. That is issue #755's ruling, and it would
  refuse coup, go-fish and gops as well.
- **Partition.** Strings are unchanged in the games that survive, but the
  corpus does not survive. This option makes "the game bends to the
  harness" the only way back to green.

### Option 3 — log only hidden-reading assignments

The derived reveal of issue #471's design note.

- **Cost.** Smallest string blast: 17 of 37 games at decisions, 2 of 37 at
  the first decision.
- **Soundness.** It is sound only if a static taint covers every way a hidden
  read reaches a write: the value, every enclosing control position, a
  `produce` tag dispatching a `produces:` arm, a move type's effect under the
  control that offers it, a Primitive's state reads, and an `Offer` or
  `TrickRound` control row. The measurement found each of these outside a
  statement-nesting walk. A position the taint misses is a silent recall
  break with every proof green: the vacuously-green class.
- **Rung.** A closed-domain analysis plus an exhaustive grid. That is a lower
  rung than construction.

### Option 5 — a state delta at every decision node (found while measuring)

At each decision node, the kernel delivers to every seat the public State
Variable slots that changed since the previous node, each with its previous
value. It does so from the one route that already delivers `asked`
(decisions.md, "Which decision a position is, the deciding seat is TOLD").

- **Recall.** A seat's log then determines the public state at every earlier
  node: by construction, at the node rather than at the write. It covers
  every write path (in-place indexed mutation, `declare`, the `again` clear,
  a phase-local variable leaving scope) and the implicit flow, with no
  analysis.
- **Why every seat.** The per-decider variant (deltas only at one's own
  decisions) is rejected. OpenSpiel's perfect-recall contract is per player
  at every state, "even the non-acting player(s)" (`spiel.h`, quoted in the
  Architect's book, Area 6).
- **Partition.** The minimal closure of today's partition that satisfies that
  contract. A transient write between two nodes is heard by no one, as
  today, so the partition moves only where a seat forgets.
- **Cost.**
  - No first-decision string moves, so `infostate_format.json` and #999's
    finish line 8 hold.
  - 35 of 37 games' later strings move.
  - Logs grow 10% overall; big-two adds 52,816.
- **What it cuts against.** The literal "an assignment is an announcement":
  the spec has to say that a seat holds the public state at every position
  it is shown, not at every write. That is a decisions.md sentence the
  operator rules.

## Counsel

### Hoyle's counsel

Not Merge Lane A. No option changes the grammar. Options 1, 3 and 5 land as
runtime emission, option 2 as a resolve verdict, all Merge Lane B. Which
reading "public to every observer, always" carries is doctrine in
`docs/decisions.md` for the operator, not surface. Hoyle stands down. The one
language-facing note: option 2's refusal would tell a designer to "announce
or reveal" a whole hand the language can only reveal one card at a time,
which is a diagnostic naming a remedy that does not exist.

### The Architect's counsel

**Headnote.** The choice is which record makes every seat's earlier views
recoverable from its present one: a record per write, or a record per game
position. The law binds the answer to derived, uniformly emitted
observations and to `forget` as the only way to lose recall.
- **Recommended:** the per-position state delta (option 5), delivered to
  every seat at every decision node.
- **Rejected:** refusing the flow (option 2), which refuses 16 of 37 games,
  12 of them sound. Logging only hidden-reading writes (option 3) is
  rejected too: its soundness rests on an analysis whose domain measurement
  already found open.
- **What it changes:** every seat's information state newly carries the
  public state at each earlier position. No seat newly learns anything it was
  not shown.
- **Info-set verdict:** derive via a per-node state delta. The partition
  moves only where a seat forgets today.
- **Precedent:** an established citation, OpenSpiel's perfect-recall
  contract over every player at every state, and the book's own principle
  that recall is proven, not assumed.

Bottom line: build option 5. The strongest case against it is that it
narrows the spec's literal "an assignment is an announcement" to "a seat
sees the public state at each position". It still moves later strings in 35
of 37 games. The operator decides which reading of public state the law
carries. If every write is an announcement, the answer is option 1 instead,
at 26 of 37 first-decision strings and #999's finish line.

1. **The decision.** Not "log or refuse". Which record makes the public half
   of a seat's information state recoverable at every later position: per
   write (option 1), per position (option 5), per hidden-reading write
   (option 3), or none, with the flow refused (option 2).
2. **The law.**
   - State Variables are public and hidden information lives only in zones
     (decisions.md, "Hidden information lives only in zones; state is
     public").
   - `forget` is the only operation that breaks perfect recall ("`forget` is
     the escape hatch").
   - Information sets are derived, never authored, and observations are
     emitted uniformly by the kernel (CLAUDE.md, load-bearing).
   - The deciding seat is told which decision a position is through the log,
     "with no second channel" (decisions.md, the Seat View rules).
   - "The whole log is rendered."
   - Every option keeps these laws except option 2, which keeps them by
     refusing a fifth of what the law admits. The literal "assignment is an
     announcement" sits in a `HIDDEN_READ_POSITIONS` reason string, not in
     decisions.md. Option 5 needs the law to say which it means, and that is
     the operator's.
3. **Precedent.**
   - P14 (Area 6, established): the perfect-recall contract is the export
     invariant. `spiel.h` states it for every player at every state,
     non-acting players included. The per-decider variant of option 5 fails
     it, and the every-seat form meets it.
   - P13 (Area 6): declared once, emitted uniformly. Options 1 and 5 emit
     from a kernel site. Option 3 emits where an analysis says to, a
     per-site decision in all but name.
   - GDL-II (Area 6, Thielscher 2010): percepts arrive per state transition,
     not per rule firing. That is the per-position grain of option 5.
   - No book precedent bears on the volume question.
4. **The options.** Option 5, for and against:
   - *Info-set derivation:* derived at the node, by construction.
   - *Closed-domain completeness:* the domain is the decision route's
     emission, one site, already an owner.
   - *Oracle:* the existing witnesses redden today and must green.

   Option 1:
   - same derivation;
   - the domain is every write door, of which there are four and not one;
   - partition refinement beyond forgetting where transients exist.

   Option 3: the domain is every hidden-read path to a write, a closed
   domain the measurement already found open in four places. Option 2: fails
   the corpus.
5. **What becomes illegal after (option 5).**
   - `infostate.py`'s Contract gains an Establishes clause: a seat's public
     state at every earlier decision node is a function of its Observation
     Log. Held by a single owner, the decision route's delta emission beside
     `asked`. Artifact: a proof module cell comparing earlier information
     states across Constructed Worlds, the depth oracle promoted into
     `tests/openspiel_ready/harness.py`. It must redden on both witnesses
     with the emission removed.
   - `observe.EVENT_PAYLOADS` gains a row. Artifact: the payload probes in
     the per-visible-fact matrix and the emission sweep
     `tests/test_observation_payloads.py`.
   - Newly illegal downstream:
     - rendering or resampling a Seat View that drops the delta events;
     - a decision route that reaches the Chooser without the delta, the same
       guard `asked` has.
   - Coq: a `pub_at_nodes` theorem beside `pub_from_log` over the delta
     event.
6. **Counsel.**
   - *For:* recall by construction at the grain OpenSpiel defines it, with no
     analysis to keep complete; no first-decision string moves, so it
     sequences cleanly beside #999; a tenth of option 1's log growth.
   - *Against:* it is a semantics choice dressed as a mechanism. It decides
     that a transient public write is heard by no one, and the spec's
     "always" reads the other way. It still regenerates every later-position
     pin in 35 of 37 games. Each delta carries previous values, so its
     rendering must be certified like any payload.
   - *What the Architect would do:* option 5, every seat, every decision
     node, sequenced as a new member of #999 Part 2's closed union, with a
     decisions.md sentence stating the per-position reading for the operator
     to rule. Option 1 is the fallback if the operator rules that every
     write is an announcement.

## Recommendation

**Option 5. At every decision node, every seat's log receives the public
State Variable slots that changed since the previous node, each with its
previous value, emitted from the route that delivers `asked`.** Merge Lane B.
It lands with a decisions.md sentence stating that a seat holds the public
state at every position it is shown, which is the operator's ruling and the
precondition. If the operator rules instead that every write is an
announcement, option 1 is the fallback, built on one door for every State
Variable write first.

Acceptance criteria:

1. **Runs.** Both witnesses (`state_recall`, `state_recall_branch`): at seat
   0's second decision the two deals give different information states.
   This reddens today.
2. **Regression-clean.**
   - `CARDLANG_GOLDEN_SEEDS=full pytest tests/test_migration_characterization.py`
     byte-identical: the delta touches no rng and no choice.
   - `tests/golden/infostate_format.json` unchanged.
   - The six stream-hash files are re-captured only after the filter-out
     check shows the delta is the whole difference.
   - Every information-state pin that moves is regenerated with the delta as
     its only diff.
3. **Info sets derive.**
   - A proof-battery cell is added: at sampled depths past the first deals,
     every seat's information states at all earlier nodes agree across
     Constructed Worlds. It must be shown red on both witnesses with the
     emission removed (a planted fault, P11).
   - Coq `pub_at_nodes` closes under the global context.
   - The partition-coverage record moves only in games the cell shows
     forgetting today.
4. **Closed-domain obligations.** One new `EVENT_PAYLOADS` row, reached by
   the emission sweep, its fields certified by the per-visible-fact matrix.
   The glossary's Observation Event entry already defers to the table. A
   name for the kind is minted in the same change if it needs one.

**What a green would prove:** the public half of every seat's information
state is perfect-recall at every decision node, by construction, for every
game. **What it would not prove:**
- the zone half, which still rests on every zone change being logged (epic
  #999 Part 1);
- that a published hidden fact is honest play: the four games that score an
  unrevealed pile into a cumulative score still publish it, and whether they
  should reveal it is issue #471's question and a rules-fidelity read of
  each game against Pagat, not done here;
- anything about a value written and overwritten between two nodes, which
  the recommended reading makes unheard by design.
