## Doctrine amendments — ruled during this review: two land, one holds

Both amend this skill's own text, both are corrections to checks it already
runs rather than new process, and the operator ruled during the review's
conversation. **One:** the output contract treats a #143 edit as code —
`tools/ready-front.sh` ranks by first mention in that body, so the edit is
re-run through the sweep and its top moves checked selectable. Two verdicts
running broke selection at exactly this step (verdict 4 stranded seven R1s
unranked; this one first ranked an unselectable epic's work). **Two:** check 3
now reads age as a flag, never a rank — an aged issue is neglected, stale, or
correctly parked, and only its body read against the tree says which (#25's
four flaggings were a stale premise; #154/#158 are parked with no wrong game
behind them).

**A third was offered and held**: extending the stopping rule with "never
settle a choice an open issue or the operator owns" (the #392 instance above).
One instance is not a class; it recurs or it stays out.
