The construct is gone; the rule it left is what this entry names. A design note
asking whether it may inject something is asking this question: DSL the kernel
already interprets is on one side, Python behaviour the kernel cannot observe is
on the other.

`instantiate` is also an ordinary verb here — a template instantiates, a rule
reference instantiates one — so it is not a retired spelling and those uses stand.
