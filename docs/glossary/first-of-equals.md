term: First of Equals
definition: The kernel rule for every [[winner]] the language ships: when two plays compare equal, the one played EARLIER wins. Invisible in a single pack and decisive in a double one (Doppelkopf, Pinochle), so it is stated rather than left to fall out of an implementation — `max` keeping its first maximal element, or a strict `>` scan in play order. The plays are read in arrival order from the [[arrival-record]], so "earlier" is a recorded fact and never seat arithmetic.
