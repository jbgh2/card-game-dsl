term: Positive
definition: The procedure parameter domain of whole numbers from 1 up, written `size : Positive`. It is no value type, so no other position may name it; the body reads the parameter as an Integer, and every `run` passes a written number of 1 or more, refused otherwise at the argument (`run betting_street(first_actor, 0, 0)` names no bet size). A computed argument is refused rather than checked at play, because expansion binds it past every check. The spec is decisions.md, "Named procedures".

status: canonical

home: `typecheck.POSITIVE_PARAM_DOMAIN`; the guard is `resolve._check_positive_arguments`
